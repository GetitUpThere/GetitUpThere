# GetitUpThere — Initial Website

This is the first static website for the GetitUpThere side-business concept.

## Files
- `index.html` — complete responsive one-page website.

## Current launch assumptions
- Standard launch price: A$300 one-off.
- A custom domain is correctly described as having its own annual registration/renewal cost.
- The site does not promise permanent free hosting.
- No email or final domain has been invented.
- The current CTA copies a reusable enquiry message instead of submitting a form.

## Initial GitHub Pages deployment
1. Create a repository in the `GetitUpThere` GitHub Organization.
2. Upload `index.html`.
3. Open repository Settings → Pages.
4. Under Build and deployment, choose `Deploy from a branch`.
5. Select `main` and `/ (root)`.
6. Save and wait for the Pages URL.

## Before public launch
- Add your real contact email or contact form.
